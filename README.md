# Abasto — demo

Demo interactiva y one-pager comercial de **Abasto**, una plataforma de reposición
de inventario por producto y sucursal, calculada a diario.

Todo el contenido es ficticio (empresa, sucursales, productos, cifras) — pensado
para mostrar el producto a potenciales clientes sin depender de ningún backend.

## Archivos

- **`index.html`** — demo interactiva completa: login con 3 roles, sugerido de
  compras, carros de compra, catálogo, sugerencias manuales, inventario, ventas
  históricas, simulador, incidencias, auditoría, documentación del modelo,
  configuración y carga de datos. Todo en un solo archivo HTML/CSS/JS, sin
  build ni dependencias externas (salvo Google Fonts).
- **`brochure.html`** — documento de una página para enviar a potenciales
  clientes: qué problema resuelve, cómo funciona, y qué incluye.

## Cómo verla

Abre `index.html` directamente en el navegador, o publícala con GitHub Pages
(Settings → Pages → Deploy from branch → `main` / `/root`).
